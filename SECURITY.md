# Política de segurança

## Característica do projeto

Este repositório é uma referência puramente educacional sobre segurança de pacotes e cadeia de suprimentos. O conteúdo contém documentação conceitual e configurações defensivas; não contém código ofensivo, exploits ou provas de conceito de ataque.

## Canal de contato

Use `security@example.com` como canal responsável até que o mantenedor substitua o endereço por um contato real.

## Como reportar problemas

Para vulnerabilidades, dados incorretos em documentação ou links quebrados:

1. Não publique informações sensíveis em uma issue pública.
2. Use um GitHub Security Advisory no repositório, se disponível.
3. Informe localização, impacto esperado e uma correção sugerida.

O projeto fará a triagem e corrigirá problemas que possam induzir práticas inseguras ou dados incorretos.
